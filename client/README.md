# 前台"正在用"客户端（now_playing.exe）

Windows 常驻小工具:登录博客后实时检测鼠标焦点所在的进程名 + 窗口标题上报后端,
首页 hero 那句「目前没想好写什么」就会变成「正在用 …」。

**带图形界面**:首次运行填一次密码即可,之后双击**静默后台常驻**,系统托盘有图标。

## 一、第一次用

1. 双击 `now_playing.exe`,弹出**设置窗口**。
2. 填 **服务器地址**(默认 `http://127.0.0.1:8080` 即可)和**后台管理员密码**。
3. 点「**保存并开始**」→ 窗口最小化到托盘,开始上报。

之后你切到浏览器刷新首页,占位就会变成「正在用 当前程序」。

- 密码用 **Windows DPAPI** 加密后存 exe 旁的 `config.json`(不落明文),
  只对这台电脑、这个用户生效,拷到别的机器解不开。
- 已在文件里填过旧明文 `password` 的,启动时会自动转成加密并清掉明文。

## 二、以后每次

双击 `now_playing.exe` → **不再弹窗**,直接静默跑 + 托盘图标。
- 若之前密码是对的 → 直接开始上报(位置在任务栏右下角托盘,`▢` 箭头展开可见)。
- 若密码被改/校验不过 → 会照常弹设置窗让你改,不会死关不掉。

## 三、托盘操作

右键托盘图标(`now_playing`):
- **显示设置**:重新打开窗口看状态/改配置
- **退出**:完全停止并退出(下次双击再启动)

窗口关闭(点×)也是最小化到托盘,后台继续跑;想彻底关用托盘「退出」。

## 四、给开发者 / 调试

```bash
python now_playing.py --once   # 打印一次当前焦点进程后退出
python now_playing.py --check  # 仅验证登录
python now_playing.py --gui    # 强制打开设置窗
```

依赖:内置 `tkinter` + 两个第三方库(仅打包进 exe):

```bash
pip install pystray pillow
```

重新打包(无控制台窗口版):

```bash
pyinstaller --noconsole --onefile --name now_playing now_playing.py
```

## 五、附注

- 需要 Node 后端正常跑在 `server` 指向的端口(默认 8080,详见仓库 README)。
- 客户端启动后会拉一份「当前在用配置」(`/api/data/config`),本机做改名/黑名单/标题应用(支持正则),再上报 `{active, app, title, icon, deviceName}` 到 `/api/data`。空闲 5 分钟报「休息中」,主动可离线;设备名固定为 `PC`(单机使用)。
- 上报断念超过 45 秒服务端判离线并从列表移除(正常会按节流节奏保活,不会离线)。
- 改名 / 正则映射 / 黑名单 / 标题应用在博客后台 `/admin.html` 的「前台"正在用"状态」里统一配。
- **监测是否正常**:设置窗口里有实时「当前焦点」一行,托盘图标悬停 tooltip 也实时显示正在使用的应用,便于确认客户端读没读到。

# Ciallo～(∠・ω&lt; )⌒☆ · 沐玺个人博客

沐玺（Mako）的个人博客静态页面，记录技术分享、随笔与生活日常。

> 内容施工中。敬请期待.................

## 功能特性

- 响应式布局，适配桌面端与移动端
- 固定吸顶导航栏 + 毛玻璃背景（backdrop-filter）
- 移动端汉堡菜单展开/收起
- 文章卡片列表（日期、分类标签、摘要、阅读链接）
- 侧边栏：关于卡片、文章分类、热门标签
- 自定义 CSS 变量主题，便于换肤

## 页面结构

| 区块 | 说明 |
| --- | --- |
| 首页（Hero） | 个人介绍 |
| 文章（Posts） | 文章列表卡片 |
| 关于（About） | 侧边栏个人简介 |
| 搜索 / 热门标签 | 侧边栏标签 |

## 目录结构

blog/
